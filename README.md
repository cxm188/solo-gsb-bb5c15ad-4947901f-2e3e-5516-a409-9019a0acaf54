# 🎲 瑞士制配对 · 桌游联赛

基于 **React + TypeScript + Vite** 的桌游联赛瑞士制（Swiss-system）配对 Web 应用。
录入选手名单与各轮赛果、轮空记录后，一键生成下一轮对阵；支持人工锁定对局后重算其余配对，
并在约束无解时给出冲突原因。

## 一条命令启动

```bash
docker compose up --build -d
```

启动后访问：

- **地址：** http://localhost:8080
- **端口：** `8080`（宿主机与容器均为 8080，可在 `docker-compose.yml` 中修改左侧端口）

停止与清理：

```bash
docker compose down          # 停止并删除容器
docker compose down --rmi local   # 同时删除构建出的镜像
```

> 镜像在构建阶段完成 `npm ci` 依赖安装与 `npm run build`（TypeScript 类型检查 + Vite 打包），
> 容器启动时通过 `vite preview` 直接托管构建产物，无需运行时再编译。

## 本地开发（无需 Docker）

```bash
npm install
npm run dev        # 开发服务器，默认 http://localhost:8080
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览生产构建
npm run test:solver  # 运行配对算法的 20 项冒烟测试
```

要求 Node.js 20+。

## 使用流程

1. **录入选手**：每行一个名字（也支持逗号/顿号分隔），最多 32 人。开赛后名单自动锁定。
2. **生成第 1 轮**：右侧面板可先指定人工锁定对局（也可不锁定），确认后生成。
3. **录入赛果**：点击对阵两侧选手名字记录胜者，或点“平”；轮空自动按胜计 1 分。
4. **生成下一轮**：上一轮全部赛果录入后自动出现下一轮预览，确认即生成。
5. **人工干预**：
   - 下一轮预览中，点每场右侧的 🔓 可锁定该场，其余对阵即时按规则重算；
   - 历史轮次中锁定若干场后，点「🔒 按锁定重算本轮」可保留这些对局、重排其余选手
     （未锁定对局上的赛果会被清空）。
6. 所有数据保存在浏览器 `localStorage`，刷新不丢失；点名单页「清空全部」可重置赛事。

## 配对规则

积分制：胜 **1 分**、平 **0.5 分**、负 **0 分**、轮空按胜计 **1 分**。

每轮配对按以下优先级求解（硬约束不满足时直接判无解）：

0. **硬约束**：每人至多参加一场；轮空者不参赛；已在历史轮次交手过的对手不得重复；
   人工锁定对局必须保留。
1. 最小化**跨积分组对局数**（积分组 = 当前总积分相同的选手集合）。
2. 在跨组数最少的方案中，最小化**所有对局的双方总积分差之和**。
3. **轮空**：人数为奇数时，优先选择从未轮空过的选手中积分最低者；
   若全员都已轮空过，则取全体中积分最低者；并列时以录入顺序最早者为准。

算法实现（`src/solver/solver.ts`）：

- 带下界剪枝的位掩码回溯，求「跨组数 × 大权重 + 积分差」加权目标的字典序最优完美匹配；
- MRV（候选数最少的选手优先）、贪心初始上界、不可行状态记忆化；
- 32 人规模下常规赛程均在毫秒级完成，并标记结果是否已证明最优（极端约束下会回退为“近似最优”最佳可行解）；
- 无解时先用带花树（Blossom）最大匹配找出在任何方案中都必然落单的选手，
  连同锁定重复、一人多锁、与轮空冲突等校验结果一起列出具体冲突原因。

## 目录结构

```
src/
├── components/          # React UI 组件（名单、积分榜、轮次、草稿对阵、锁定面板）
├── lib/tournament.ts    # 积分榜/赛果统计、localStorage 持久化
├── solver/solver.ts     # 瑞士制配对求解器（含无解诊断）
├── solver/solver.test.ts# 求解器冒烟测试（npm run test:solver）
├── types.ts             # 全局数据模型
├── App.tsx              # 应用状态与交互编排
└── main.tsx / styles.css
Dockerfile               # 依赖安装 + 构建纳入镜像，启动即服务
docker-compose.yml       # 单服务，映射 8080:8080
```
